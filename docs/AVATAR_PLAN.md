# 시장 아바타 제작 계획

> 동의서 서명과 동의 영상 촬영이 끝난 다음 날부터 진행할 수 있는 계획입니다.
> 서식은 [CONSENT_FORM.md](CONSENT_FORM.md), 데모 화면은 `web/avatar.html` 입니다.

## 먼저: 연동 없이 가는 파일럿 (권장)

파일럿이라면 **아무것도 합성하지 않는 것**이 가장 빠르고 안전합니다.
합성을 안 하면 동의 영상도, 업체 계약도, 제작 대기도 없습니다.

| | 합성하는 길 | **합성 안 하는 길** |
|---|---|---|
| 얼굴 | AI 아바타 제작 (동의 영상 + 업체 필요) | **시장님이 고른 사진 한 장** |
| 목소리 | AI 음성 복제 (동의 + 업체 필요) | **브라우저 내장 음성** |
| 준비 기간 | 며칠~몇 주 | **오늘** |
| 비용 | 업체 요금 | **0원** |
| 외부 연동 | 필요 | **없음 (Anthropic API 뿐)** |
| 법적 부담 | 초상권·음성권·선거법 | 사진 사용 허락만 |

`web/avatar.html` 이 이미 이 방식으로 동작합니다.

### 사진

`web/portrait.jpg` 에 시장님이 직접 고른 사진을 넣으면 화면에 들어갑니다.
없으면 자리 표시가 나옵니다. **합성물이 아니라 실제 사진**이므로 딥페이크가 아니고,
아바타 제작 절차가 필요 없습니다. 사진 사용 허락만 구두로 받으시면 됩니다.

> 이 파일은 `.gitignore` 로 막아 두었습니다. 공개 저장소에 올라가지 않습니다.

### 목소리

화면의 **‘음성 안내 켜기’** 버튼을 누르면 브라우저에 내장된 음성 합성이 답변을
읽어 줍니다. 크롬·엣지·사파리·안드로이드에 기본으로 들어 있어 **API 키도, 비용도,
외부 연동도 없습니다.**

시장님 목소리는 아닙니다. 그 점은 화면 상단 AI 배지로 이미 알리고 있습니다.
파일럿에서 확인할 것은 "음성 안내가 실제로 쓸모 있는가"이지 "누구 목소리인가"가
아닙니다. 쓸모 있다는 것이 확인된 다음에 시장님 목소리로 바꾸면 됩니다.

낭독 문장은 서버가 `to_speakable()` 로 다듬어 내려줍니다. 근거 번호 `[2]` 는 빼고
URL 은 "화면의 링크를 확인해 주세요"로 바꿉니다 (`tests/test_chat_stream.py` 에서 검증).

### 이 길로 가면 미팅이 이렇게 됩니다

1. 완성된 챗봇을 시연 — 시장님 사진과 음성 안내까지 동작
2. "여기 목소리를 시장님 목소리로 바꾸면 어떻겠습니까?" 하고 제안
3. 마음에 들어 하시면 그때 동의서와 동의 영상 ([CONSENT_FORM.md](CONSENT_FORM.md))

**빈 자리를 보여주며 설득하는 것보다, 동작하는 것을 보여주고 업그레이드를 제안하는
편이 훨씬 쉽습니다.**

---

## 왜 아바타를 먼저 만들 수 없는가

"아바타를 만들어서 시장님께 보여드리고 그 자리에서 동의서를 받는다"는 순서는
**어느 업체를 쓰든 불가능합니다.** 제작 업체가 막습니다.

| 업체 | 실존 인물 아바타 제작 조건 |
|---|---|
| HeyGen | 본인이 정해진 문구를 말하는 동의 영상 필수 |
| Synthesia | 본인 육성 동의 영상 + 서면 동의 필수 |
| D-ID | 초상권자 동의 확인 절차 필수 |
| 딥브레인AI | 계약 및 본인 동의 확인 후 촬영 진행 |

업로드 단계에서 동의 영상이 없으면 거부됩니다. 그래서 순서는 반드시
**동의 → 촬영 → 제작**입니다.

## 대신 이렇게 하면 미팅이 성사됩니다

1. **데모를 먼저 보여드립니다** — `web/avatar.html` 을 노트북이나 휴대폰으로 시연.
   아바타 자리는 비어 있지만, 완성되면 어떤 모습인지 그대로 보입니다.
   실제 충주시 자료로 답하는 것까지 그 자리에서 확인하실 수 있습니다.
2. **그 자리에서 동의서에 서명**받습니다. ([서식](CONSENT_FORM.md))
3. **그 자리에서 휴대폰으로 동의 영상 30초를 촬영**합니다. ([대본](CONSENT_FORM.md#ii-동의-영상-촬영-대본))
4. 이어서 아바타용 정면 영상 2~3분, 음성용 낭독 5분을 촬영합니다.
5. **당일 또는 다음 날 제작 착수.**

한 번의 미팅에서 다 끝납니다. 두 번 만날 필요가 없습니다.

## 업체 선택

### 국내 업체를 권합니다

시청 서비스로 확장할 것을 생각하면 국내 업체가 유리합니다.

| | 국내 (딥브레인AI, 이스트소프트 등) | 글로벌 (HeyGen, Synthesia 등) |
|---|---|---|
| 한국어 입모양 | 한국어에 맞춰 학습됨 | 영어 기준이라 어색할 수 있음 |
| 데이터 처리 위치 | 국내 | 해외 — 개인정보 검토 필요 |
| 공공 조달 | 레퍼런스 있음 | 절차가 복잡함 |
| 속도·가격 | 견적 필요 | 셀프서비스로 빠름 |
| 파일럿 적합성 | 계약 절차가 다소 무거움 | 바로 시작 가능 |

**파일럿 단계**에서는 빠르게 결과를 보는 것이 중요하므로 글로벌 셀프서비스도
선택지입니다. 다만 **시청 공식 서비스로 넘어갈 때는 국내 업체로 다시 검토**해야
합니다. 이 점을 처음부터 염두에 두고, 원본 촬영본은 어느 업체에나 넘길 수 있도록
고품질로 보관하세요.

> 요금과 약관은 자주 바뀌므로 여기 적지 않았습니다. 계약 전 직접 확인해 주세요.
> 동의서 제7조 ④항에 **선택한 업체명을 반드시 기재**해야 합니다.

## 구현 방식 — 실시간 생성은 권하지 않습니다

답변할 때마다 아바타 영상을 새로 생성하는 방식은 파일럿에 맞지 않습니다.

| 방식 | 지연 | 비용 | 파일럿 |
|---|---|---|---|
| ① 정지 이미지 + TTS 음성 | 거의 없음 | 음성 비용만 | 가장 가벼움 |
| ② **정지 이미지 + 말하는 클립 루프 + TTS** | 거의 없음 | 음성 비용만 | **권장** |
| ③ 답변마다 립싱크 영상 생성 | 답변당 수 초~수십 초 | 분당 과금, 큼 | 비권장 |

**②번을 권합니다.** 아바타 영상 클립을 몇 개만 미리 만들어 두고(대기 / 말하는 중 /
고개 끄덕임), 답변은 TTS 음성으로 재생하면서 '말하는 중' 클립을 루프합니다.
입모양이 글자와 정확히 맞지는 않지만, 안내 챗봇에서는 충분히 자연스럽고
**지연이 없다는 것이 훨씬 중요합니다.** 질문하고 20초를 기다리면 아무도 안 씁니다.

`web/avatar.html` 이 이미 ②번 구조로 되어 있습니다. 아바타 자리가 `.frame` 안의
SVG 로 되어 있고, 상태(`data-state`)가 `idle` / `thinking` / `speaking` 으로 바뀝니다.
영상 클립이 준비되면 SVG 를 `<video>` 로 바꾸고 상태에 따라 소스만 전환하면 됩니다.

### 필요한 클립 목록

촬영 때 이것들을 염두에 두시면 좋습니다.

| 상태 | 길이 | 내용 |
|---|---|---|
| 대기 | 5~10초 루프 | 정면을 보고 가볍게 눈을 깜빡이는 정도 |
| 말하는 중 | 10~15초 루프 | 자연스럽게 말하는 모습 |
| 인사 | 3~5초 | 가볍게 목례하거나 미소 |

## 코드에 이미 준비된 것

- **아바타 데모 화면** `web/avatar.html` — 상태 전환, 근거 표시, AI 고지 배지까지 동작
- **AI 고지 상시 표시** — 동의서 제3조 요건. 화면 상단에 고정되어 스크롤해도 사라지지 않습니다
- **음성 연결부** `app/voice/` — 업체 정해지면 `.env` 몇 줄로 붙습니다
- **선거법 자동 중단** — `ELECTION_DAY` 설정 시 90일 전부터 음성·아바타 기능 자동 중단
- **철회 대응** — `VOICE_CONSENT_ON_FILE=false` 로 바꾸면 즉시 전체 중단

### 철회 요청이 오면

동의서 제6조에 따라 **당일 안에** 처리해야 합니다.

```bash
# 1. 즉시 중단
VOICE_CONSENT_ON_FILE=false   # .env 수정 후 재시작

# 2. 모델·원본 폐기 (업체 대시보드에서 아바타·음성 모델 삭제)
# 3. 원본 촬영본 삭제
# 4. 7일 이내 서면 통지
```

## 남은 확인 사항

- [ ] 업체 선정 — 파일럿용 1곳
- [ ] 촬영 장소·장비 (단색 배경, 1080p 이상, 조용한 곳)
- [ ] 아바타 클립 3종 촬영 계획
- [ ] 원본 촬영본 보관 장소 — **공개 저장소·공용 클라우드 금지** (동의서 제7조)
- [ ] `ELECTION_DAY` 에 넣을 다음 지방선거일 확인
