# 음성(TTS) 업체 선정

> **지금 상태**: 코드는 붙일 준비가 끝났고, 업체는 아직 고르지 않았습니다.
> 개발 환경이 외부망에 닿지 않아 **음성 샘플을 직접 만들어 들려드릴 수 없었습니다.**
> 아래 기준으로 후보를 좁혔으니, 데모를 직접 들어보시고 정해 주세요.

## 두 단계로 나눠서 봐야 합니다

| 단계 | 쓰는 목소리 | 동의 필요 | 지금 가능 |
|---|---|---|---|
| **1단계** | 상용 라이선스 성우 목소리 (시장님 목소리 아님) | ❌ 불필요 | ✅ 바로 가능 |
| **2단계** | 시장님 실제 목소리를 학습한 AI 음성 | ✅ 서면 동의 필수 | ⏸ [동의 절차](PERSONA_CONSENT.md) 후 |

1단계를 먼저 붙여서 "음성 안내가 있으면 실제로 쓸 만한가"를 확인한 뒤, 2단계로 가는 것을
권합니다. 음성이 별 도움이 안 되는 것으로 드러나면 굳이 동의 절차를 밟을 이유가 없습니다.

## 시청 서비스에서 중요한 순서

일반 서비스와 우선순위가 다릅니다.

1. **라이선스가 공공·상업 이용에 열려 있는가** — 가장 중요합니다. "개인 사용 무료"인 목소리를
   시청 서비스에 쓰면 나중에 전부 다시 만들어야 합니다.
2. **국내에서 처리되는가** — 시민 민원 문장이 해외 서버로 나가면 개인정보 검토가 복잡해집니다.
   국내 리전이 있으면 조달·보안 심사가 훨씬 수월합니다.
3. **한국어가 자연스러운가** — 특히 숫자·날짜·행정 용어("제2025-33호", "3월 2일까지").
   영어권 모델은 이 부분에서 티가 많이 납니다.
4. 비용 — 안내 문장은 짧아서 어느 업체든 부담이 크지 않습니다. 마지막에 보세요.

## 후보

| 업체 | 성격 | 이 프로젝트 관점에서 |
|---|---|---|
| **네이버 클로바 보이스** (NCP) | 국내 클라우드, 한국어 특화 | 국내 리전·공공 조달 경험·한국어 품질 세 가지가 다 맞습니다. **1단계 추천** |
| **타입캐스트** (네오사피엔스) | 국내, 성우 라이선스 명확 | 목소리 선택지가 많고 감정 표현이 좋습니다. 상업 이용 조건 확인 필요 |
| **Microsoft Azure Speech** | 글로벌, ko-KR 뉴럴 음성 | 품질 안정적, 한국 리전 있음. 기존 Azure 계약이 있다면 유리 |
| **Google Cloud TTS** | 글로벌, ko-KR 음성 | 무난하고 저렴. 국내 리전 이슈 확인 필요 |
| **ElevenLabs** | 글로벌, 음성 복제 최강 | 표현력은 가장 좋지만 **2단계(음성 복제)용**입니다. 1단계에 쓰기엔 과합니다 |

> 요금과 약관은 수시로 바뀌므로 여기에 적지 않았습니다. 계약 전 각 업체 페이지에서
> **최신 상업 이용 약관과 요금**을 직접 확인해 주세요.

## 정하면 붙이는 법

업체 SDK 를 미리 박아 넣지 않고, 대부분의 상용 TTS 가 공통으로 쓰는
`POST + JSON + 오디오 응답` 형태를 환경변수로 기술하게 해 두었습니다.
**코드 수정 없이 `.env` 몇 줄이면 붙습니다.**

```bash
VOICE_PROVIDER=custom
VOICE_CONSENT_ON_FILE=true          # 1단계는 상용 성우라 true 로 둬도 됩니다
VOICE_ENDPOINT=https://<업체 TTS 엔드포인트>
VOICE_HEADERS={"X-API-KEY": "${VOICE_API_KEY}"}
VOICE_BODY={"text": "{text}", "speaker": "{voice_id}", "format": "mp3"}
VOICE_MIME=audio/mpeg
VOICE_API_KEY=<발급받은 키>
VOICE_ID=<선택한 목소리 id>
```

`{text}` 와 `{voice_id}` 자리가 실제 값으로 치환됩니다. 따옴표나 줄바꿈이 든 답변도
JSON 이 깨지지 않게 처리합니다 (`tests/test_voice.py` 에서 검증).

규격이 많이 다른 업체라면 `app/voice/providers.py` 에 클래스 하나만 추가하면 됩니다.

확인:

```bash
curl localhost:8000/voice/status
curl -X POST localhost:8000/voice/speak \
     -H 'Content-Type: application/json' \
     -d '{"text":"안녕하세요, 충주시 안내입니다."}' --output test.mp3
```

## 코드에 이미 들어간 안전장치

- **동의 잠금** — `VOICE_CONSENT_ON_FILE=true` 가 아니면 어떤 설정을 해도 합성이 거부됩니다.
- **선거법 자동 중단** — `ELECTION_DAY=2026-06-03` 처럼 선거일을 넣어두면 **90일 전부터
  선거일까지 음성 기능이 자동으로 꺼집니다.** 한국시간 기준으로 판정하므로 서버가 UTC 여도
  하루가 밀리지 않습니다. 경계일(90일째, 91일째, 선거 당일)까지 테스트했습니다.
- **낭독용 정리** — 화면용 표기가 그대로 읽히지 않게 다듬습니다.
  근거 번호 `[2]` 는 빼고, URL 은 "화면의 링크를 확인해 주세요"로 바꿉니다.
