# 음성·아바타 제작 전 확인 사항

> 요청하신 3번(시장 보이스)과 4번(아이콘·이모티콘·아바타)에 대한 답입니다.
> **먼저 보여드리고 컨펌받는다**는 원칙은 그대로 지킵니다. 다만 그 전에 정리해야 할
> 법적 전제가 있어 먼저 적습니다.

## 왜 유튜브에서 바로 가져오면 안 되는가

이동석 시장은 실존 인물이자 선출직 공직자입니다. 유튜브 영상에서 음성이나 얼굴을
추출해 AI 로 복제하는 것은 세 가지 권리를 동시에 건드립니다.

| 권리 | 근거 | 위험 |
|---|---|---|
| **음성권·초상권** (인격권) | 민법상 인격권, 판례 | 본인 동의 없는 복제는 그 자체로 침해 |
| **저작권·저작인접권** | 저작권법 | 영상 제작자에게 별도 권리가 있음 |
| **공직선거법** | 공직선거법 제82조의8 | 선거일 90일 전부터 후보자 관련 AI 합성물(딥페이크) 제작·유포 금지 |

특히 마지막 항목은 형사처벌 대상이고, 지방선거가 있는 해에는 **시장 본인이 동의해도
기간 내에는 금지**됩니다. 챗봇이 정치적 목적이 아니어도 "시장의 모습·목소리로 말하는
합성물"이라는 형식 자체가 문제가 될 수 있어, 선거 일정과 겹치지 않게 관리해야 합니다.

## 그래서 이렇게 진행합니다

### 1단계 — 동의 없이 지금 할 수 있는 것 (진행 중)
- 챗봇 본체: 충주시 공식 자료 기반 질의응답 — **완료**
- 캐릭터형 마스코트 시안: 실존 인물을 닮게 그리지 않은 창작 캐릭터 — 시안 준비 중
- 음성: 상용 라이선스 한국어 TTS 후보 (시장 목소리 아님) — 후보 준비 중

### 2단계 — 서면 동의 확보 후에만 할 수 있는 것 (보류)
- 시장 실제 목소리의 AI 음성 모델
- 시장 얼굴을 닮은 실사형 아바타
- 시장 얼굴 기반 아이콘·이모티콘

## 체크리스트

2단계는 아래가 **전부** 충족될 때만 시작합니다.

- [ ] 이동석 시장 **본인의 서면 동의서** (음성·초상 AI 활용 범위·기간·철회 방법 명시)
- [ ] '이동석TV' 채널 영상의 **제작·저작권자 이용 허락** (채널 운영 주체가 시장 본인이 아닐 경우)
- [ ] 충주시청 담당 부서의 **공식 사용 승인** (공식 서비스로 운영할 경우)
- [ ] **공직선거법 제한기간 확인** — 선거일 90일 전부터 해당 기능 중단 계획 수립
- [ ] 이용자에게 **AI 합성 음성/영상임을 화면에 상시 표시**하는 UI 확정
- [ ] **철회 절차** 문서화 — 시장이 동의를 철회하면 음성 모델·아바타를 즉시 폐기

체크가 끝나면 `.env` 에서만 켭니다:

```bash
VOICE_PROVIDER=elevenlabs
VOICE_CONSENT_ON_FILE=true    # 동의서 원본을 확보한 뒤에만 true
```

> 코드에도 같은 잠금이 걸려 있습니다. `Settings.voice_enabled` 는
> `VOICE_CONSENT_ON_FILE=true` 가 아니면 어떤 설정을 해도 `False` 를 돌려줍니다.
> (`tests/test_config.py` 에서 검증)

## 챗봇이 시장을 사칭하지 않는 이유

시스템 프롬프트에 사칭 금지를 명시했습니다. 사용자가 "시장님이세요?"라고 물으면
시장 본인이 아니라 충주시 자료를 안내하는 AI 라고 밝힙니다. 시장 개인의 발언·공약·
정치적 입장은 근거 자료에 있는 공식 발표가 아닌 한 답하지 않습니다.

음성·아바타를 나중에 붙이더라도 이 원칙은 바뀌지 않습니다. "시장을 닮은 안내 캐릭터"
이지 "시장 본인"이 아니며, 화면에 항상 그렇게 표시합니다.

## 저장소 정책

음성 샘플과 얼굴 이미지는 **저장소에 커밋하지 않습니다**. `.gitignore` 에서
`assets/voice/**`, `assets/face/**` 를 차단해 두었습니다. 공개 저장소에 인격권 대상
자료가 올라가면 되돌릴 수 없습니다.
