# 로드맵

## 1단계 — 비공개 테스트 (현재)

챗봇 본체는 동작 가능한 상태입니다. 남은 것은 실제 데이터 연결입니다.

- [x] 하이브리드 검색 (벡터 + BM25 + RRF)
- [x] 근거 인용 답변 (Claude Opus 5, 스트리밍)
- [x] 매일 21:00 KST 자동 수집
- [x] 변경·정정·마감 반영
- [x] 수집 감사 / 미응답 질문 추적
- [x] 테스트용 웹 UI
- [ ] **충주시청 게시판 선택자 검증** ← 다음 할 일 (외부망 되는 서버에서)
- [ ] 첫 전체 수집 및 답변 품질 확인
- [ ] 실제 질문 30~50개로 평가셋 구성

### 평가셋을 만드는 이유

"잘 되는 것 같다"로는 개선 여부를 알 수 없습니다. 실제로 들어올 법한 질문 30~50개와
정답 근거를 정해 두면, 프롬프트나 검색 설정을 바꿀 때마다 좋아졌는지 나빠졌는지
숫자로 확인할 수 있습니다. 1단계 테스트 중에 나온 질문을 그대로 모으면 됩니다.

## 4단계 — 모두의AI 연동 (12월 예정)

연동 담당자와 기술 문서가 아직 없으므로, 그때 바로 붙일 수 있게 **지금은 경계만
깨끗하게** 유지합니다.

현재 구조에서 준비된 것:

- 답변 생성이 `app/llm/client.py` 한 곳에 모여 있어 교체·병행이 쉬움
- 검색과 생성이 분리되어 있어, 상대 플랫폼이 생성만 담당하는 형태도 가능
- `/chat` (단발) 과 `/chat/stream` (SSE) 을 모두 제공해 어느 쪽 규격이든 대응 가능

연동 시 확인할 것:

- [ ] 모두의AI 측 API 규격 / 인증 방식
- [ ] 대화 상태를 누가 보관하는지 (우리 `conversations` 테이블 vs 상대 플랫폼)
- [ ] 출처 표시 방식 — 근거 링크를 상대 UI 에서 어떻게 렌더링할지
- [ ] 개인정보 처리 책임 주체
