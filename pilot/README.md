# 파일럿 페이지 — 충주 AI 시장

`chungju-ai-mayor.html` 은 claude.ai 아티팩트로 배포되는 **서버 없는 파일럿**입니다.
페이지가 직접 Claude 를 호출하므로 설치도, DB 도, API 키도 필요 없습니다.

- 사진: 화면의 카메라 버튼으로 넣으면 그 기기에 저장됩니다 (외부로 나가지 않음).
- 음성: 브라우저 내장 음성 합성. 외부 연동 없음.
- 지식: 파일 안의 `KNOWLEDGE` 상수. 파일럿용 기본 자료이며, 정식 운영 시에는
  이 저장소의 수집 파이프라인(`app/ingest`)이 충주시청 자료로 매일 밤 갱신합니다.

이 파일은 `<title>` 부터 시작하는 본문 조각입니다. 아티팩트 플랫폼이 `<html>`/`<head>`/`<body>` 를
씌워 배포하므로, 브라우저에서 직접 열려면 그 태그를 감싸야 합니다.
